# Trips API

REST API implementation for managing trips and clients using ASP.NET Core and Entity Framework Core with a layered architecture.

## Features
* Trip management endpoints
* Client registration and assignment to trips
* Database integration with Entity Framework Core
* Layered architecture with models, DTOs, repositories, services, and controllers

## Technologies
* C#
* ASP.NET Core
* Entity Framework Core
* SQL Server

## Architecture
* Models
* DTOs
* DAL
* Repositories
* Services
* Controllers

## How to run

dotnet restore  
dotnet run
